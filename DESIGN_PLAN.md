# Premium Hybrid — English Teaching Portfolio
Status: recruiter-focused visual direction, superseding the earlier palette. All CV, experience, credentials, testimonials, and teaching materials must be genuine and verified before publication.

## Visual system
- Audience: Tokyo-based eikaiwa hiring teams, private and international schools, corporate English programs.
- Mood: composed competence and scanability, with human warmth in the personal story and concrete teaching evidence in the portfolio.
- Palette: ink #232a31 and Prussian blue #244c66 for structure; warm paper #f4efe6 for the canvas; vermilion #c14d34 reserved for interview actions; aged brass #a98247 reserved for the Army instructor credential. Retire the repeated sage and peach panels.
- Page roles: home communicates candidate fit; experience reads like a cool-toned chronology; about uses a warmer clay accent; portfolio reads like a documentary case file; résumé stays paper-white; contact makes the interview action salient.
- Typography: DM Sans for recruiter scanning and actions; Playfair Display only where a reflective/editorial voice helps, with local/system fallbacks.
- Style: one strongest action per view, clear evidence hierarchy, readable contrast, responsive layout, keyboard-visible focus.

## Main pages — build one at a time
1. Home — professional introduction, employer value, featured sections, contact CTA. Initial draft committed.
2. About — genuine story, teaching approach, strengths, career goals. **Initial structure committed**; personal copy awaits confirmation.
3. Experience — verified teaching roles, responsibilities, impact, target age ranges.
4. Résumé center — responsive on-screen CV plus real downloadable PDF and print-ready A4 stylesheet; optional ATS-friendly version.
5. Teaching studio — interactive original demonstrations; start with one real lesson.
6. Resources — lesson plans and worksheets, preview/download.
7. Credentials — education, training, and verified certificates.
8. For employers — Eikaiwa / Schools / Business English views that select relevant real experience.
9. Contact — employer inquiry form, anti-spam controls, private Supabase storage; no public exposure of submissions.

## Working process
GitHub main repository is source of truth. Build page > review content > test > commit > Vercel deploy. Supabase is reserved for genuine database needs, not simple static pages. Work only within free plan capacity. Do not promise a live URL before Vercel confirms a successful deployment.

## Content restrictions
Do not fabricate years of experience, school names, student outcomes, certifications, testimonials, photos, visa status, or contact details.
Do not publish a placeholder résumé as if it were real.
Avoid collecting sensitive information in the contact form; secure all stored messages with appropriate database access rules.
